# AWS 프리 티어 가입 방법

2025년 7월 15일 이후 신규 AWS 계정은 가입 시 무료 플랜(최대 6개월)과 유료 플랜 중 하나를 선택하는 구조로 바뀌었다. 이 문서는 바뀐 구조를 기준으로 가입 절차를 정리한다.

## 무료 플랜과 유료 플랜 비교

2025-07-15 이후 만든 신규 AWS 계정은 가입 과정에서 무료 플랜(Free Plan)과 유료 플랜(Paid Plan) 중 하나를 선택한다.

| 구분 | 무료 플랜 | 유료 플랜 |
|---|---|---|
| 기간 | 최대 6개월(또는 크레딧 소진 시 먼저 종료) | 제한 없음 |
| 크레딧 | 가입 시 100달러, 온보딩 활동으로 최대 200달러까지 | 동일하게 최대 200달러 |
| 크레딧 소진 후 | 요금 청구 없이 서비스 중단 | 표준 요금으로 즉시 과금 |
| 서비스 범위 | 일부 서비스만 | 150여 개 전체 서비스 |
| 전환 | 유료 플랜으로 언제든 업그레이드 가능 | - |

## 시작하기 전 준비물

- 본인 명의 이메일 주소(인증 코드 수신 및 계정 복구용)
- 본인 명의 신용/체크카드(해외결제 가능한 카드. 무료 플랜 기간엔 청구되지 않지만 본인 확인 목적으로 요구됨)
- 전체 이름·주소 등 연락처 정보

## 가입 절차

1. aws.amazon.com/free에 접속하여 [무료 계정 생성]을 선택한다.
2. AWS 계정 이메일 주소와 AWS 계정 이름을 입력한다. 계정 이메일 주소는 계정 복구에 사용되므로 실제로 수신 가능한 주소를 입력한다. 계정 이름은 이후 설정에서 변경할 수 있다.
3. [이메일 주소 확인]을 선택한다. 입력한 이메일로 인증 코드가 발송되며, 이 시점부터 계정 생성 절차가 시작된다.
4. 수신한 인증 코드를 입력하여 이메일 인증을 완료한다.
5. 로그인에 사용할 AWS 계정 암호를 설정하고 확인란에 동일하게 입력한다.
6. 계정 플랜을 선택한다. 무료 플랜(6개월)은 워크로드 규모 조정과 일부 AWS 서비스·기능 액세스가 제외되며, 단순 학습·테스트 목적이면 무료 플랜으로 충분하다.
7. 연락처 정보를 입력한다. 전체 이름, 국가 코드·전화번호, 국가, 주소, 시/우편번호 등을 입력하고 AWS 이용계약 동의 체크박스를 선택한다.
8. 결제 정보를 등록한다. 청구 국가를 선택하고 신용카드 번호, 만료일, 보안 코드, 카드 소유자 이름, 청구지 주소를 입력한다. AWS는 본인 확인·사기 방지 목적으로 카드에 1달러(또는 상당액)를 3~5일간 예치했다가 환급하며, 무료 플랜을 선택한 경우 유료 플랜으로 직접 업그레이드하기 전까지 별도 요금은 청구되지 않는다.
9. 등록을 완료하면 계정 활성화가 시작된다. 활성화는 보통 몇 분 안에 끝나며, 완료되면 이메일로 안내가 온다.

AWS 정책이나 계정 상태에 따라 전화번호 인증(SMS/음성 코드) 단계가 추가로 나타날 수 있다.

## 가입 후 바로 할 일

- **루트 계정 대신 IAM 사용자 만들기**: 루트 계정은 결제·계정 설정 등 최소한의 작업에만 쓰고, 평소 작업은 IAM에서 별도 사용자를 만들어 사용한다.
- **예산 알림(Budget) 설정**: Billing 콘솔에서 예산을 만들고 특정 금액 도달 시 이메일 알림이 오도록 설정해두면, 무료 크레딧 소진 시점을 놓치지 않는다.
- **MFA(다단계 인증) 활성화**: 루트 계정에 MFA를 걸어두는 것을 AWS 공식 문서에서도 권장한다.
- **리전 확인**: 기본 리전이 의도한 곳(예: 서울 ap-northeast-2)인지 콘솔 우측 상단에서 확인한다.
