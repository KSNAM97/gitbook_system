# AWS 탄력적 IP(Elastic IP) 적용하기

개념에 대한 자세한 설명은 이론 2.  AWS EC2 - 배포 문서의 10. ENI와 Elastic IP 섹션 참고. 이 문서에서는 실제 콘솔에서 탄력적 IP를 할당하고 인스턴스에 연결하는 절차를 다룬다.

## 탄력적 IP 소개

- EC2 인스턴스를 생성하면 고유의 퍼블릭 IP를 할당받는다. 하지만 이렇게 할당받은 IP는 인스턴스를 중지하고 다시 실행시키면 다른 IP로 변경된다. 이는 사용 중인 서비스나 애플리케이션에 큰 영향을 준다.
- 탄력적 IP(Elastic IP, EIP)는 동적 클라우드 컴퓨팅 환경에서 사용할 수 있는 정적 IPv4 주소다. 이 주소는 AWS 계정에 할당되며, 사용자가 명시적으로 해제하기 전까지 그 상태를 유지한다.
- 탄력적 IP를 사용하면 인스턴스의 장애 발생 시 다른 인스턴스로 IP 주소를 신속하게 재매핑하여 높은 가용성을 유지할 수 있다.
- 2024년부터 AWS는 어떤 인스턴스에도 연결되지 않은 유휴 상태의 탄력적 IP, 그리고 인스턴스에 연결되어 있더라도 사용하지 않아 유휴 상태로 판단되는 탄력적 IP에 대해 시간당 소액의 요금을 부과한다. 실제로 사용하지 않는 탄력적 IP는 과금을 막기 위해 반드시 해제(Release)해 둔다.

## 탄력적 IP 적용 절차

1. 인스턴스를 선택하여 퍼블릭 IP 주소를 확인한다.
2. 오른쪽 상단의 [인스턴스 상태]에서 [인스턴스 중지]를 선택한다. 중지된 인스턴스를 다시 시작하면 퍼블릭 IP 주소가 변경되는 것을 확인할 수 있다.
3. 탄력적 IP 페이지로 이동하여 [탄력적 IP 주소 할당]을 선택한다.
4. 기본 설정을 그대로 두고 [할당]을 선택하면 IP 주소가 할당된다.
5. 할당된 탄력적 IP의 이름을 변경한다.
6. 탄력적 IP 목록에서 오른쪽 상단의 [작업] > [탄력적 IP 주소 연결]을 선택한다.
7. 인스턴스 항목에서 연결할 EC2 인스턴스를 선택하고 [연결]을 선택하면 연결이 완료된다.

연결이 완료되면 EC2 인스턴스의 퍼블릭 IP 주소가 탄력적 IP에서 할당받은 주소로 변경된다. 이후 인스턴스를 중지하고 다시 시작해도 퍼블릭 IP 주소는 고정된 채로 유지된다.
