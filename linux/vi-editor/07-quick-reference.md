# VI 명령어 퀵 레퍼런스

> **Tag:** #Linux #Vi #Vim #QuickReference #CheatSheet  
> **핵심 요약:** VI/Vim의 파일 열기, 모드 전환, 이동, 편집, 치환, 범위 조작, 셸 연동, Swap 복구 명령을 빠르게 확인하는 문서.

---

## 1. 명령어 문법 (Configuration)

### 1. 파일 열기

```bash
vi <파일>                       # 파일 열기 또는 새 버퍼 생성
vi +10 <파일>                   # 파일을 열고 10번째 줄로 이동
vi + <파일>                     # 파일을 열고 마지막 줄로 이동
vi +/pattern <파일>             # pattern의 첫 일치 위치로 이동
vi -R <파일>                    # 읽기 전용 모드로 열기
vi <파일1> <파일2>              # 여러 파일을 인수 목록으로 열기
```

### 2. 모드 전환

```text
명령 → 입력
i  현재 커서 앞에서 입력
a  현재 커서 뒤에서 입력
I  첫 비공백 문자 앞에서 입력
A  줄 끝에서 입력
o  아래에 새 줄 생성
O  위에 새 줄 생성

입력 → 명령
Esc

명령 → 명령행
:
```

### 3. 저장과 종료

```vim
:w                             " 현재 파일 저장
:w <파일>                      " 지정 파일에 저장
:q                             " 변경이 없을 때 종료
:wq                            " 저장 후 종료
:x                             " 변경된 경우 저장 후 종료
:q!                            " 변경 사항을 버리고 종료
:e!                            " 변경을 버리고 디스크 내용 재로드
```

명령 모드:

```vim
ZZ                             " :x와 유사하게 저장 후 종료
ZQ                             " :q!와 유사하게 강제 종료
```

### 4. 커서 이동

```vim
h j k l                        " 왼쪽·아래·위·오른쪽 이동
5j 5k                          " 아래·위로 5줄 이동

w e b                          " 다음 단어·단어 끝·이전 단어
W E B                          " 공백 기준 WORD 단위 이동

0 ^ $                          " 줄 첫 칸·첫 비공백·줄 끝
gg G 25G                       " 파일 처음·끝·25번째 줄

Ctrl+f Ctrl+b                  " 한 화면 아래·위
Ctrl+d Ctrl+u                  " 반 화면 아래·위
H M L                          " 화면 위·중앙·아래
```

### 5. 삭제

```vim
x X                            " 현재 문자·왼쪽 문자 삭제
dw de db                       " 단어 시작·끝·이전 방향 삭제
dd                             " 현재 줄 삭제
5dd                            " 현재 줄부터 5줄 삭제
d0 d^                          " 줄 첫 칸·첫 비공백 방향 삭제
d$ D                           " 줄 끝까지 삭제
dG dgg                         " 파일 끝·처음 방향 삭제
```

### 6. 복사와 붙여넣기

```vim
yy                             " 현재 줄 복사
5yy                            " 현재 줄부터 5줄 복사
yw ye y$                       " 단어·단어 끝·줄 끝까지 복사
p P                            " 커서 뒤·앞에 붙여넣기
3p                             " 세 번 붙여넣기

"ayy                           " a 레지스터에 현재 줄 복사
"ap                            " a 레지스터 내용 붙여넣기
:registers                     " 레지스터 목록과 내용 확인
```

### 7. 변경·실행 취소

```vim
rX                             " 현재 문자 하나를 X로 교체
R                              " Replace 모드 진입
cw ce                          " 단어 변경
cc                             " 현재 줄 변경
C                              " 커서부터 줄 끝까지 변경

u                              " 마지막 변경 실행 취소
Ctrl+r                         " 취소한 변경 다시 실행
.                              " 마지막 변경 반복
:undolist                      " Undo 목록 확인
:earlier 5m                    " 5분 전 상태로 이동
:later 5m                      " 5분 후 상태로 이동
```

### 8. Ex 범위

```vim
:3                             " 3번째 줄로 이동
:$                             " 마지막 줄로 이동

:3,10d                         " 3~10번째 줄 삭제
:.,+3d                         " 현재 줄부터 총 4줄 삭제
:-3,.d                         " 위 3줄부터 현재 줄까지 삭제
:.,$d                          " 현재 줄부터 마지막 줄까지 삭제
:%d                            " 전체 줄 삭제

:3,10y                         " 3~10번째 줄 복사
:.,$y                          " 현재 줄부터 마지막 줄까지 복사
:%y                            " 전체 줄 복사

:3,10move 20                   " 3~10줄을 20번째 줄 뒤로 이동
:3,10copy 20                   " 3~10줄을 20번째 줄 뒤에 복사
```

### 9. 검색

```vim
/pattern                       " 아래 방향으로 pattern 검색
?pattern                       " 위 방향으로 pattern 검색
n                              " 현재 검색 방향의 다음 결과
N                              " 반대 방향의 다음 결과
*                              " 현재 단어를 아래 방향으로 검색
# " 현재 단어를 위 방향으로 검색
:nohlsearch                    " 검색 강조 일시 제거
```

### 10. 치환

```vim
:s/old/new/                    " 현재 줄의 첫 일치 치환
:s/old/new/g                   " 현재 줄의 모든 일치 치환
:6s/old/new/g                  " 6번째 줄의 모든 일치 치환
:2,7s/old/new/g                " 2~7번째 줄에서 치환
:%s/old/new/g                  " 파일 전체에서 치환
:%s/old/new/gc                 " 일치할 때마다 확인하며 치환
:%s/old/new/gi                 " 대소문자를 무시하고 치환
:%s/old//gn                    " 변경 없이 일치 개수 확인
```

정확한 단어:

```vim
:%s/\<linux\>/WIN/gc           " linux라는 완전한 단어만 확인하며 치환
```

IP 주소:

```vim
:%s/192\.168\.1/172.16.100/gc  " 점을 리터럴로 처리해 IP 대역 치환
```

줄 끝 공백:

```vim
:%s/\s\+$//                    " 모든 줄의 끝 공백 제거
```

빈 줄:

```vim
:g/^\s*$/d                     " 공백만 있거나 완전히 빈 줄 삭제
```

### 11. 셸 연동

```vim
:!<명령>                       " 외부 셸 명령 실행
:read !<명령>                  " 현재 줄 다음에 명령 결과 삽입
:10read !<명령>                " 10번째 줄 다음에 결과 삽입
:$read !<명령>                 " 파일 마지막에 결과 삽입

:.!<명령>                      " 현재 줄을 명령 출력으로 교체
:1,10!sort                     " 1~10번째 줄 정렬
:%!sort                        " 전체 버퍼 정렬

:w !diff -u <백업> -           " 현재 버퍼와 백업 파일 비교
```

### 12. 관리자 권한 저장

처음부터 권장:

```bash
sudoedit <파일>                 # 사용자 편집기를 이용해 안전하게 관리자 파일 편집
```

현재 버퍼 저장:

```vim
:execute 'write !sudo tee ' . shellescape(expand('%:p')) . ' >/dev/null'
                                " 현재 파일 경로를 안전하게 인용해 sudo tee로 저장
:set nomodified                 " 현재 버퍼를 저장된 상태로 표시
```

단순 경로용 축약형:

```vim
:w !sudo tee % > /dev/null      " 현재 버퍼를 sudo tee로 원본 경로에 기록
```

### 13. Swap 복구

```bash
vim -r                          # 복구 가능한 Swap 목록 확인
vim -r <파일>                   # 특정 파일의 Swap 복구 시도
lsof <파일>                     # 파일을 열고 있는 프로세스 확인
fuser -v <파일>                 # 파일 사용 프로세스 확인
ls -la <디렉터리>               # 숨김 Swap 파일을 포함해 조회
```

복구본 별도 저장:

```vim
:w /tmp/file.recovered          " 복구 결과를 별도 파일로 저장
```

원본과 비교:

```vim
:!diff -u <원본> /tmp/file.recovered
                                " 원본과 복구본 차이 확인
```

> 다른 Vim 프로세스가 파일을 편집 중인지 확인하기 전에는 Swap 파일을 바로 삭제하지 않는다.

## 2. 빠른 조회표 (Configuration)

### 1. 모드

| 모드 | 진입 | 역할 |
|---|---|---|
| 명령 | 실행 직후, `Esc` | 이동·편집 |
| 입력 | `i`, `a`, `o` 등 | 문자 입력 |
| 명령행 | `:` | 저장·종료·치환 |

### 2. 범위

| 범위 | 의미 |
|---|---|
| 생략 | 현재 줄 |
| `.` | 현재 줄 |
| `$` | 마지막 줄 |
| `%` | 전체 |
| `3,10` | 3~10번째 줄 |
| `.,+3` | 현재 포함 총 4줄 |
| `-3,.` | 위 3줄부터 현재 |
| `.,$` | 현재부터 마지막 |

### 3. 치환 플래그

| 플래그 | 의미 |
|---|---|
| `g` | 줄 안의 모든 일치 |
| `i` | 대소문자 무시 |
| `c` | 일치할 때마다 확인 |
| `n` | 변경 없이 개수 표시 |

### 4. 정규식

| 패턴 | 의미 |
|---|---|
| `^` | 줄 시작 |
| `$` | 줄 끝 |
| `\<` | 단어 시작 |
| `\>` | 단어 끝 |
| `\.` | 리터럴 점 |
| `\s` | 공백 문자 |
| `\+` | 바로 앞 패턴 1회 이상 |
| `\(...\)` | 캡처 그룹 |
| `\1` | 첫 번째 캡처 |
| `&` | 전체 일치 문자열 |

### 5. 셸 연동

| 명령 | 동작 |
|---|---|
| `:!cmd` | 외부 명령 실행 |
| `:read !cmd` | 출력 삽입 |
| `:10read !cmd` | 10번째 줄 다음에 삽입 |
| `:10!cmd` | 10번째 줄을 출력으로 교체 |
| `:%!cmd` | 전체 버퍼 필터 |
| `:write !cmd` | 버퍼를 명령 입력으로 전달 |

### 6. 편의 옵션

```vim
:set number                     " 줄 번호 표시
:set nonumber                   " 줄 번호 해제
:set relativenumber             " 상대 줄 번호 표시
:set hlsearch                   " 검색 결과 강조
:set ignorecase                 " 검색 시 대소문자 무시
:set smartcase                  " 대문자가 포함되면 대소문자 구분
:set paste                      " 자동 들여쓰기를 억제하는 붙여넣기 모드
:set nopaste                    " 붙여넣기 모드 해제
:set undofile                   " Persistent Undo 활성화
:syntax on                      " 문법 강조 활성화
```

## 3. 검증 명령어 모음 (Verification)

Vim 내부:

```vim
:file                           " 현재 파일명과 수정 상태 확인
:pwd                            " 현재 작업 디렉터리 확인
:buffers                        " 열린 버퍼 목록 확인
:registers                      " 레지스터 내용 확인
:changes                        " 변경 위치 목록 확인
:undolist                       " Undo 목록 확인
:set modified?                  " 저장되지 않은 변경 여부 확인
:set readonly?                  " 읽기 전용 옵션 확인
:set swapfile?                  " Swap 파일 사용 여부 확인
:set directory?                 " Swap 파일 저장 경로 확인
:version                        " Vim 버전과 컴파일 기능 확인
```

외부 셸:

```bash
command -v vi                   # 실행될 vi 경로 확인
command -v vim                  # 실행될 vim 경로 확인
type -a vi vim                  # alias·함수·실행 파일 후보 확인
lsof <파일>                     # 파일을 연 프로세스 확인
fuser -v <파일>                 # 파일 사용 프로세스 확인
vim -r                          # 복구 가능한 Swap 목록 확인
```

>  **핵심 요약**
> - 명령 모드 복귀: `Esc`
> - 입력: `i`, `a`, `o`
> - 저장: `:w`, `:wq`, `:x`
> - 종료: `:q`, `:q!`
> - 편집: 오퍼레이터+모션+카운트
> - 치환: `:%s/old/new/gc`
> - 명령 결과 삽입: `:read !명령`
> - 현재 버퍼 비교: `:w !diff -u backup -`
> - 복구: `vim -r`
