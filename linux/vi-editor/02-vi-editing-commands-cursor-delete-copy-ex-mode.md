# ⌨ VI 편집 명령어 (커서·삭제·복사·Ex Mode 범위 조작)

> **Tag:** #Linux #Vi #Vim #Motion #Yank #Delete  
> **핵심 요약:** VI/Vim의 편집 명령은 카운트, 오퍼레이터, 모션을 조합한다. `3dw`, `5dd`, `y$`처럼 규칙을 조합하면 이동·삭제·복사 범위를 빠르게 지정할 수 있다.

---

## 1. 개요 (Overview)

VI/Vim의 편집 명령은 `[count] + [operator] + [motion]` 구조를 따른다.

```text
[count] + [operator] + [motion]
```

대표 오퍼레이터로는 삭제를 뜻하는 `d`, 복사/Yank를 뜻하는 `y`, 삭제 후 입력 모드로 전환하는 `c`(Change), 들여쓰기의 `>`, 내어쓰기의 `<` 가 있다.

| 오퍼레이터 | 의미 |
|---|---|
| `d` | 삭제(Delete) |
| `y` | 복사/Yank |
| `c` | 삭제 후 입력 모드(Change) |
| `>` | 들여쓰기 |
| `<` | 내어쓰기 |

대표 모션으로는 다음 단어 시작으로 이동하는 `w`, 단어 끝으로 이동하는 `e`, 이전 단어 시작으로 이동하는 `b`, 현재 줄 끝의 `$`, 현재 줄 첫 칸의 `0`, 파일 끝의 `G`, 파일 처음의 `gg`, 대응하는 괄호로 이동하는 `%` 가 있다.

| 모션 | 의미 |
|---|---|
| `w` | 다음 단어 시작 |
| `e` | 단어 끝 |
| `b` | 이전 단어 시작 |
| `$` | 현재 줄 끝 |
| `0` | 현재 줄 첫 칸 |
| `G` | 파일 끝 |
| `gg` | 파일 처음 |
| `%` | 대응하는 괄호 |

이 오퍼레이터와 모션을 조합하면 다음과 같이 사용할 수 있다.

```vim
dw          " 다음 단어 시작 전까지 삭제
de          " 현재 단어 끝까지 삭제
3dw         " 3번의 w 이동 범위를 삭제
y$          " 현재 위치부터 줄 끝까지 복사
dG          " 현재 위치부터 파일 끝까지 삭제
```

삭제·복사한 내용은 Vim 레지스터에 저장된다. 레지스터 확인은 다음과 같이 한다.

```vim
:registers
```

축약형:

```vim
:reg
```

이름 있는 레지스터를 사용할 수도 있다.

```vim
"ayy        " 현재 줄을 a 레지스터에 복사
"ap         " a 레지스터 내용 붙여넣기
```

시스템 클립보드는 Vim 빌드 옵션에 따라 사용할 수 있다. 다음 명령으로 확인한다.

```vim
:version
```

다음 기능이 있는지 확인한다.

```text
+clipboard
+xterm_clipboard
```

사용 예는 다음과 같다.

```vim
"+yy
"+p
```

## 2. 표준 사용 템플릿 (Configuration)

> **적용 환경:** RHEL 계열(RHEL·Rocky Linux·AlmaLinux) 및 대부분의 Linux 배포판 공통.

### Step 1. 문자 단위 이동

```vim
h           " 왼쪽
j           " 아래
k           " 위
l           " 오른쪽

5j          " 아래로 5줄
5k          " 위로 5줄
10l         " 오른쪽으로 10칸
```

### Step 2. 단어 단위 이동

```vim
w           " 다음 word 시작
W           " 공백으로 구분되는 다음 WORD 시작
e           " 현재·다음 word 끝
E           " 현재·다음 WORD 끝
b           " 이전 word 시작
B           " 이전 WORD 시작
```

- 소문자 모션은 문자 종류와 구두점을 세분화한다.
- 대문자 모션은 공백으로 구분되는 큰 단위를 사용한다.

### Step 3. 줄 단위 이동

```vim
0           " 줄의 0번 칸
^           " 줄의 첫 번째 비공백 문자
$           " 줄 끝
g_          " 줄의 마지막 비공백 문자
```

### Step 4. 화면 및 문서 이동

```vim
H           " 화면 위쪽
M           " 화면 중앙
L           " 화면 아래쪽

Ctrl+f      " 한 화면 아래
Ctrl+b      " 한 화면 위
Ctrl+d      " 반 화면 아래
Ctrl+u      " 반 화면 위

gg          " 파일 처음
G           " 파일 끝
25G         " 25번째 줄
:25         " 25번째 줄
```

### Step 5. 문자 삭제

```vim
x           " 커서 위치 문자 삭제
X           " 커서 왼쪽 문자 삭제
5x          " 커서부터 5문자 삭제
```

### Step 6. 모션을 이용한 삭제

```vim
dw          " 현재 위치부터 다음 word 시작 전까지 삭제
de          " 현재 위치부터 word 끝까지 삭제
dW          " 현재 위치부터 다음 WORD 시작 전까지 삭제
db          " 현재 위치부터 이전 word 시작까지 삭제
dB          " 현재 위치부터 이전 WORD 시작까지 삭제

d0          " 현재 위치부터 줄 첫 칸 방향으로 삭제
d^          " 현재 위치부터 첫 비공백 문자 방향으로 삭제
d$          " 현재 위치부터 줄 끝까지 삭제
D           " d$와 동일

dG          " 현재 위치부터 파일 끝까지 삭제
dgg         " 현재 위치부터 파일 처음까지 삭제
```

### Step 7. 줄 삭제

```vim
dd          " 현재 줄 삭제
5dd         " 현재 줄을 포함하여 5줄 삭제
```

> **주의:** `5dd`는 현재 줄 아래의 5줄을 추가로 삭제하는 것이 아니라 현재 줄을 포함한 총 5줄을 삭제한다.

### Step 8. 복사와 붙여넣기

```vim
yy          " 현재 줄 복사
5yy         " 현재 줄을 포함한 5줄 복사

yw          " w 모션 범위 복사
ye          " word 끝까지 복사
y$          " 현재 위치부터 줄 끝까지 복사
y0          " 현재 위치부터 줄 첫 칸 방향으로 복사
y%          " 현재 위치에서 대응 괄호까지 복사
```

붙여넣기:

```vim
p           " 문자 단위는 커서 뒤, 줄 단위는 현재 줄 아래
P           " 문자 단위는 커서 앞, 줄 단위는 현재 줄 위
3p          " 세 번 붙여넣기
```

> **참고:** `Y`의 동작은 전통 vi와 Vim 호환 설정에 따라 차이가 있을 수 있다. 줄 복사는 `yy`를 사용하는 것이 명확하다.

### Step 9. 변경과 치환

```vim
rX          " 현재 문자 하나를 X로 교체
R           " Replace 모드
cw          " 단어 변경
ce          " 단어 끝까지 변경
cc          " 현재 줄 변경
C           " 현재 위치부터 줄 끝까지 변경
```

Replace 또는 Insert 모드 종료:

```text
Esc
```

### Step 10. 실행 취소·재실행·반복

```vim
u           " 실행 취소
Ctrl+r      " 취소한 작업 다시 실행
.           " 마지막 변경 작업 반복
```

Undo 목록 확인:

```vim
:undolist
```

시간 기준 이동:

```vim
:earlier 5m
:later 5m
```

변경 단위 기준:

```vim
:earlier 1f
:later 1f
```

### Step 11. Ex 범위 주소

| 주소 | 의미 |
|---|---|
| `.` | 현재 줄 |
| `$` | 마지막 줄 |
| `%` | 전체 줄, `1,$`와 유사 |
| `3` | 3번째 줄 |
| `3,10` | 3~10번째 줄 |
| `.,$` | 현재 줄부터 마지막 |
| `.,+3` | 현재 줄부터 아래 3줄, 총 4줄 |
| `-3,.` | 현재 줄 위 3줄부터 현재 줄 |

### Step 12. Ex 범위 삭제

```vim
:.delete
:10delete
:3,10delete
:.,20delete
:.,+3delete
:-3,.delete
:.,$delete
:%delete
```

축약형:

```vim
:.d
:10d
:3,10d
:.,$d
:%d
```

> **참고:** `:.,-3d`처럼 시작 주소가 종료 주소보다 뒤에 있는 역방향 범위는 오류 또는 확인을 유발할 수 있다. 위 3줄부터 현재 줄까지는 `:-3,.d`로 작성한다.

### Step 13. Ex 범위 복사

```vim
:.yank
:10yank
:3,10yank
:.,20yank
:.,+3yank
:-3,.yank
:.,$yank
:20,$yank
:%yank
```

축약형:

```vim
:.y
:3,10y
:.,$y
:%y
```

> **참고:** `:.,+3y`는 현재 줄을 포함해 총 4줄을 복사한다.

### Step 14. Ex 범위 이동과 복사

```vim
:3,10move 20
:3,10copy 20
```

축약형:

```vim
:3,10m 20
:3,10t 20
```

- `move 20`: 3~10번 줄을 20번 줄 뒤로 이동
- `copy 20` 또는 `t 20`: 3~10번 줄을 20번 줄 뒤에 복사

### Step 15. 편집 옵션

```vim
:set number
:set nonumber
:set relativenumber
:set hlsearch
:set nohlsearch
:set ignorecase
:set smartcase
:syntax on
```

붙여넣기 모드:

```vim
:set paste
```

붙여넣기 후 반드시 해제:

```vim
:set nopaste
```

> **참고:** 최신 Vim/터미널의 bracketed paste 지원 여부에 따라 `paste` 옵션이 필요하지 않을 수 있다.

## 3. 검증 및 트러블슈팅 (Verification & Troubleshooting)

### 3-1. 상태 확인

```vim
:file
:pwd
:set
:set all
:registers
:undolist
:changes
```

### 3-2. 대표 트러블슈팅

#### 시나리오 1. 붙여넣기 후 들여쓰기가 계단식으로 밀린다

```vim
:set paste
```

입력 모드에서 붙여넣는다.

```vim
i
```

완료 후:

```text
Esc
```

반드시 해제:

```vim
:set nopaste
```

#### 시나리오 2. `dd`를 실수로 실행했다

현재 세션에서:

```vim
u
```

취소한 작업을 다시 실행:

```vim
Ctrl+r
```

이미 저장했더라도 같은 Vim 세션의 Undo 기록이 남아 있다면 `u`로 되돌리고 다시 저장할 수 있다.

```vim
u
:w
```

> **참고:** 저장 후 `:q!`를 실행하는 것은 이미 디스크에 저장된 내용을 복원하지 않는다.

#### 시나리오 3. `:%d` 후 저장해서 빈 파일이 되었다

Vim 세션이 아직 열려 있고 Undo 기록이 있다면:

```vim
u
:w
```

세션을 종료했다면 다음 순서로 복구 자료를 확인한다.

```bash
ls -la <디렉터리>
find <디렉터리> -maxdepth 1 \
  \( -name '.*.sw?' -o -name '*.bak' -o -name '*.rpmnew' -o -name '*.rpmsave' \)
```

> **주의:** 정상 저장 후 Vim까지 종료했다면 Swap 파일이 삭제될 수 있다. Swap을 일반 백업처럼 의존하면 안 된다.

Persistent Undo 설정 예시:

```vim
:set undofile
:set undodir?
```

`~/.vimrc` 예시:

```vim
set undofile
set undodir=~/.vim/undo//
```

디렉터리 생성:

```bash
mkdir -p ~/.vim/undo
chmod 700 ~/.vim/undo
```
