# System Wiki (Full)

> Rocky Linux 9 기반 시스템 관리, 쉘 스크립트, 데이터베이스, HTML, Docker 학습 자료 전체 모음

이 문서는 Obsidian System 볼트의 전체 학습 노트를 GitBook 형식으로 1:1 미러링한 자료입니다. 항목별로 개념 개요, 표준 설정 템플릿, 검증/트러블슈팅까지 실무에서 바로 참고할 수 있도록 정리되어 있습니다.

## 구성

- **Linux** — Rocky Linux 9 기반 시스템 관리 전체 (기초, 파일/디렉터리, VI, 사용자·그룹·권한, 허가권·소유권, 압축, RAID·LVM, 파티션·마운트, 파일공유, 네트워크 서비스)
- **Shell Script** — Bash 쉘 스크립트 문법과 실전 활용
- **Database** — MariaDB/MySQL 설치, SQL 문법, 실습
- **HTML** — HTML 기초 구조와 태그
- **Docker** — 컨테이너 가상화, 이미지, 네트워크, Compose
