# HTML - 태그의 구분 · 인라인 텍스트 요소

> **Tag:** #HTML #블록요소 #인라인요소 #태그구분
> **핵심 요약:** 블록 요소는 한 줄 전체를 차지하고, 인라인 요소는 내용 크기만큼만 차지하며 같은 줄에 나란히 배치된다.

---

## 1. 개요 (Overview)

블록 레벨 요소(Block Element)는 자신이 속한 영역의 **가로 너비를 모두 차지**하는 요소이다. 블록 요소 앞뒤에는 자동으로 줄바꿈이 발생하며, `width`, `height`, `margin`, `padding`을 자유롭게 설정할 수 있다. 주로 페이지의 구조나 영역을 만들 때 사용한다.

```html
<!-- 블록 요소 예시 -->
<h1>제목은 한 줄을 모두 차지한다</h1>
<p>문단도 한 줄 전체를 차지한다</p>
<div>div도 블록 요소다</div>
```

인라인 요소(Inline Element)는 **내용의 크기만큼만** 영역을 차지하는 요소이다. 옆에 공간이 있으면 같은 줄에 나란히 배치되며, 일반적으로 `width`, `height`가 적용되지 않고 위/아래 `margin`도 제한적이다. 주로 문장 안에서 특정 글자나 부분을 꾸밀 때 사용한다.

```html
<!-- 인라인 요소 예시 — 같은 줄에 배치됨 -->
<strong>스트롱 태그</strong>
<em>em 태그는 글씨를 기울입니다.</em>
<mark>mark 태그는 형광처리합니다.</mark>
```

블록과 인라인의 실제 동작을 비교하면 다음과 같다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>블록 vs 인라인</title>
</head>
<body>
    <h1>블록 요소와 인라인 요소</h1>

    <!-- 블록: 각각 다른 줄에 출력 -->
    <p>p 태그는 블록 요소 — 한 줄 전체를 차지한다</p>
    <p>다음 p 태그는 자동으로 다음 줄에 배치된다</p>

    <!-- 인라인: 같은 줄에 나란히 출력 -->
    <strong>스트롱</strong>
    <em>이탤릭</em>
    <mark>형광펜</mark>
</body>
</html>
```

>  `<p>` 는 블록, `<strong>` / `<em>` / `<mark>` 는 인라인

블록과 인라인을 구별하는 핵심 기준은 하나다: **줄 전체를 차지하면 블록, 내용만큼만 차지하면 인라인**.

| 블록 요소 | 인라인 요소 |
|---|---|
| `<h1>`~`<h6>` | `<a>` |
| `<p>` | `<strong>`, `<b>` |
| `<div>` | `<em>` |
| `<ul>`, `<ol>`, `<li>` | `<span>` |
| `<table>` | `<img>` |
| `<form>` | `<input>` |
| `<hr>` | `<label>` |

---

## 자주 하는 실수

| 실수 | 올바른 방법 |
|---|---|
| 인라인 요소 안에 블록 요소 넣기 | 인라인(`<span>`) 안에 `<p>` 등 블록 넣으면 안 됨 |
| 인라인에 width/height 직접 지정 | CSS `display: inline-block` 으로 전환 후 적용 |
