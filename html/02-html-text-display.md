# 📝 HTML - 텍스트 표시 방법

> **Tag:** #HTML #텍스트 #h태그 #p태그 #br #인라인텍스트 #부트캠프
> **핵심 요약:** h1~h6(제목), p(문단), br(줄바꿈), 인라인 텍스트 태그들로 HTML에서 텍스트를 구조적으로 표시한다.

---

## 1. 📖 개요 (Overview)

제목 태그 `<h>`는 `<h1>`부터 `<h6>`까지 6단계로 구성되며, 숫자가 클수록 글자가 작아진다.

```html
<h1>h태그는 제목을 표시합니다. h1</h1>
<h2>h태그는 제목을 표시합니다. h2</h2>
<h3>h태그는 제목을 표시합니다. h3</h3>
<h4>h태그는 제목을 표시합니다. h4</h4>
<h5>h태그는 제목을 표시합니다. h5</h5>
<h6>h태그는 제목을 표시합니다. h6</h6>
```

문단 태그 `<p>`는 하나의 태그가 하나의 문단을 표현하며, 문단과 문단 사이에 공백(여백)이 자동으로 생긴다.

```html
<h1>윤동주 - 별헤는 밤</h1>

<p>계절이 지나가는 하늘에는
가을로 가득 차 있습니다.</p>

<p>나는 아무 걱정도 없이
가을 속의 별들을 다 헤일 듯합니다.</p>

<p>여기는 &nbsp;&nbsp;&nbsp;&nbsp; 솔데스크 학원입니다.</p>
```

`&nbsp;`는 Non-Breaking Space의 줄임말로, 공백을 여러 개 표시할 때 사용한다.

HTML은 Enter(줄바꿈)를 무시하고 하나의 공백으로 처리하기 때문에, 문서에서 Enter를 눌러도 줄바꿈이 되지 않는다. 실제로 줄바꿈을 적용하려면 `<br />` 태그를 사용해야 한다.

```html
계절이 지나가는 하늘에는
가을로 가득 차 있습니다. <br>

나는 아무 걱정도 없이
가을 속의 별들을 다 헤일 듯합니다. <br>

가슴속에 하나둘 새겨지는 별을 <br>
이제 다 못 헤는 것은 <br>
쉬이 아침이 오는 까닭이요, <br>
```

`<b>`와 `<strong>`은 화면상으로는 둘 다 굵게 보이지만 의미가 다르다.

| 태그 | 역할 | 스크린 리더 |
|---|---|---|
| `<b>` | 시각적 굵기 표현 (표현용) | 특별한 강조 없음 |
| `<strong>` | 내용 강조 (의미 포함) | 더 강하게 발음 |

접근성(시각 장애인 대응)을 고려하면 `<strong>` 을 우선 사용하는 것이 좋다.

그 밖의 인라인 텍스트 태그 예시는 다음과 같다.

```html
<b>굵게 표시</b>
<strong>중요한 내용 강조</strong>
<em>기울임(이탤릭)</em>
<u>밑줄</u>
<s>취소선</s>
<mark>형광펜</mark>
<big>약간 크게</big>
<small>약간 작게</small>

100<sup>2</sup>   <!-- 100² -->
100<sub>2</sub>   <!-- 100₂ -->

<hr>  <!-- 수평 구분선 -->
```

## 🖥️ 실습 예제

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>텍스트 표시 실습</title>
</head>
<body>
    <h1>윤동주 - 별헤는 밤</h1>

    <p>계절이 지나가는 하늘에는<br>
    가을로 가득 차 있습니다.</p>

    <hr>

    <p>
        <b>굵게</b> /
        <strong>강조 굵게</strong> /
        <em>이탤릭</em> /
        <u>밑줄</u> /
        <s>취소선</s> /
        <mark>형광펜</mark>
    </p>

    <p>
        <big>크게</big> /
        <small>작게</small> /
        100<sup>2</sup> /
        H<sub>2</sub>O
    </p>
</body>
</html>
```

---

## ⚠️ 자주 하는 실수

| 실수 | 올바른 방법 |
|---|---|
| Enter로 줄바꿈 시도 | `<br />` 태그 사용 |
| 공백 여러 칸을 스페이스로 입력 | `&nbsp;` 사용 |
| `<b>` 와 `<strong>` 혼동 | 의미 강조면 `<strong>`, 스타일만이면 `<b>` |
