# 📦 HTML - 컨테이너 태그

> **Tag:** #HTML #div #span #컨테이너 #전역속성 #부트캠프
> **핵심 요약:** `<div>`(블록)와 `<span>`(인라인)은 요소를 묶는 컨테이너 태그로, CSS와 함께 사용해야 의미가 생긴다.

---

## 1. 📖 개요 (Overview)

컨테이너 태그는 여러 HTML 요소를 하나로 묶어 관리하기 위해 사용한다. 여러 요소를 하나의 그룹으로 묶을 때, 웹 페이지의 영역을 구분할 때, 여러 요소에 같은 CSS 스타일을 적용할 때, 요소의 위치나 배치를 설정할 때 사용한다.

`<div>` 태그는 Division(구역)의 약자로, **웹 페이지의 영역이나 구역을 나눌 때** 사용하는 대표적인 블록 컨테이너 태그이다.

```html
<div>
    <h1>공지사항</h1>
    <p>공지사항 내용입니다.</p>
</div>
```

`<div>` 자체에는 기본 모양이나 스타일이 없으며, CSS와 함께 사용하여 크기, 색상, 위치, 여백 등을 설정한다. 주요 용도로는 헤더 영역, 메뉴 영역, 본문 영역, 사이드바 영역, 푸터 영역 만들기 등이 있다.

`<span>` 태그는 문장이나 글자의 **특정 부분만 묶을 때** 사용하는 인라인 컨테이너 태그이다.

```html
<p>오늘 날씨는 <span>맑음</span>입니다.</p>

<!-- CSS 스타일 적용 예 -->
<p>오늘 날씨는 <span style="color: red;">맑음</span>입니다.</p>
```

`<span>` 자체에도 기본 모양이나 스타일이 없으며, 주로 문장 일부에 CSS 스타일을 적용할 때 사용한다.

`<div>`와 `<span>`의 차이를 실습으로 확인하면 다음과 같다.

```html
<!-- div: 각각 다른 줄에 출력 (블록) -->
<div>첫 번째 영역</div>
<div>두 번째 영역</div>

<!-- span: 같은 줄에 나란히 출력 (인라인) -->
<span>첫 번째 글자</span>
<span>두 번째 글자</span>
```

전역 속성(Global Attributes)이란 **모든 HTML 태그에서 공통으로 사용할 수 있는 속성**이다.

```html
<태그명 property="value" property="value">콘텐츠</태그명>
```

| 속성 | 역할 |
|---|---|
| `id` | 요소에 **고유한 이름** 부여 (페이지 내 유일) |
| `class` | 요소를 **그룹별로 묶을 수 있는** 식별자 |
| `style` | 요소에 직접 **CSS 스타일** 선언 |
| `title` | 마우스 오버 시 **툴팁** 텍스트 제공 |

```html
<div id="header" class="container" style="color: blue;" title="헤더 영역">
    <h1>사이트 제목</h1>
</div>
```

## 🖥️ 실습 예제

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>컨테이너 태그 실습</title>
</head>
<body>
    <div>
        <h1>HTML 문서를 만듭니다.</h1>
        <hr>
        <img src="../image/dog.jpg" width="150" alt="강아지 이미지">
    </div>

    <div>
        <h2>오늘 점심은 뭘 먹을까?</h2>
        <p>오늘 점심 메뉴를 추천해주세요</p>
        <p>오늘 점심은 <span style="color: red;">간짜장 곱배기</span>를 먹어야겠어요</p>
        <img src="../image/cat.jpg" width="150" alt="고양이 이미지">
    </div>
</body>
</html>
```

> 💡 컨테이너를 사용하여 특정 영역을 묶으면 CSS나 JavaScript로 상호작용 가능

## ⚠️ 자주 하는 실수

| 실수 | 올바른 방법 |
|---|---|
| `<span>` 안에 `<div>` 넣기 | 인라인 요소 안에 블록 요소 불가 |
| `id`를 같은 페이지에서 중복 사용 | `id`는 페이지 내 유일해야 함 |
| `class`와 `id` 혼동 | `id`=하나, `class`=여러 요소에 공유 가능 |
