# 🧩 Shell Script - Metacharacters (메타문자)

> **Tag:** #Linux #ShellScript #Bash #Metacharacters #Glob #BraceExpansion #명령치환 #산술확장 #Redirection #Pipe
> **핵심 요약:** 메타문자는 쉘이 일반 문자와 다르게 특별한 의미로 해석하는 문자이다. 크게 **① 글롭(glob) 패턴 매칭**, **② 중괄호 확장(Brace Expansion)**, **③ 변수·치환·산술 연산**, **④ 리다이렉션/파이프**, **⑤ 명령 연결/제어**, **⑥ 주석**의 6가지로 분류하며, 작은따옴표(`'`)·큰따옴표(`"`)·백슬래시(`\`)로 메타문자의 특별한 의미를 무력화(escape)할 수 있다.

---

## 1. 📖 개요 (Overview)

메타문자는 파일명 검색, 변수 사용, 명령 출력 저장, 명령 연결 등에 사용되는 특별한 의미를 가진 문자이다. 쉘은 명령어를 실제로 실행하기 **전에** 메타문자를 먼저 해석·확장한 뒤 실제 명령으로 넘긴다. 예를 들어 `ls *.txt` 에서 `*` 는 쉘이 먼저 `.txt` 로 끝나는 모든 파일 이름으로 확장한 뒤 `ls` 에 전달한다. 메타문자는 작은따옴표(`'`), 큰따옴표(`"`), 백슬래시(`\`) 없이 사용했을 때만 특별한 의미를 갖는다. 이 세 가지로 감싸면 일반 문자로 취급된다(단, 중괄호 확장·명령 치환은 큰따옴표 안에서도 동작).

글롭 패턴에서 `*` 는 **0글자 이상**의 임의 문자열, `?` 는 **정확히 1글자**, `[]` 는 **대괄호 안에 지정된 문자 집합 중 정확히 1글자**와 매치된다. 세 메타문자 모두 "패턴 매칭 대상 파일이 실제로 존재해야" 확장된다는 공통점이 있다. `[abc]` 는 a, b, c 중 하나(순서 무관, `[abc]`=`[cba]`), `[a-z]`·`[0-9]` 는 범위 지정이며 `[0-9a-zA-Z]` 처럼 여러 범위 조합도 가능하다. `[!abc]` 또는 `[^abc]` 는 부정 패턴으로 a·b·c를 제외한 문자 1개를 뜻한다. 대괄호는 항상 **문자 1개 전용**이다. `file[0-9].txt` 는 `file0.txt`~`file9.txt` 만 매치되고 `file123.txt` 는 매치되지 않는다(자릿수가 다르므로).

중괄호 확장(`{a,b,c}`, `{1..5}`)은 **파일의 존재 여부와 무관하게 쉘이 문자열 자체를 조립·생성**하는 기능이다. 반면 글롭(`*`, `?`, `[]`)은 실제 파일 시스템에 존재하는 대상과 매치되어야만 확장된다. `echo file{1,3,5}.txt` → 파일이 없어도 `file1.txt file3.txt file5.txt` 문자열이 그대로 출력된다. 범위 확장으로 `{1..5}`, `{01..10}`(0 패딩), `{a..f}` 도 가능하다. 중첩 조합 `{A,B}{1,2}.txt` → `A1.txt A2.txt B1.txt B2.txt` (첫 중괄호 펼친 후 다음 중괄호와 조합). **공백이 있으면 확장되지 않는다**: `File{A, B, C}` 는 콤마 뒤 공백 때문에 확장 실패, 그대로 출력된다. 중괄호 확장은 큰따옴표·작은따옴표로 **중괄호 앞뒤만** 감쌌을 때는 동작하지만, **중괄호 표현 자체를 통째로** 따옴표 안에 넣으면 확장되지 않는다.

큰따옴표는 문자열을 하나로 묶으면서도 **변수 확장(`$변수`), 명령치환(`$(...)`), 산술확장(`$((...))`)을 모두 허용**한다. 반면 작은따옴표는 내부의 모든 문자를 완전히 일반 문자로 취급하여 **어떠한 확장도 차단**한다. `name="Park"; echo "Hello $name"` → `Hello Park` (큰따옴표는 변수 확장 O). `name="Park"; echo 'Hello $name'` → `Hello $name` 그대로 출력(작은따옴표는 변수 확장 X). 변수명과 뒤에 오는 문자를 구분해야 할 때는 `${변수}` 형태를 사용한다. `var=10; echo "${var}file"` → `10file`. `"$varfile"` 로 쓰면 `varfile` 이라는 존재하지 않는 변수로 해석되어 빈 값이 출력된다.

`$(( ))` 는 산술식을 계산한 **결과값을 반환**하여 출력·변수 저장에 사용한다. 반면 `(( ))` 는 계산 결과를 화면에 출력하지 않고, 변수 값을 변경하거나 **조건의 참/거짓을 종료 코드(exit code)로 반환**하는 데 사용한다. `echo $((10 > 5))` → 값으로 `1`(참) 또는 `0`(거짓) 반환. `(( 10 > 5 )); echo $?` → 조건이 참이면 `$?` 가 `0`, 거짓이면 `1`(일반적인 참/거짓 논리와 반대인 종료 코드 규칙에 유의). 증감 연산자는 `++var`(전위, 먼저 증가 후 사용), `var++`(후위, 먼저 사용 후 증가) 모두 지원한다. 나눗셈 `/` 은 정수 나눗셈이라 소수점 이하가 버려진다. `echo $((10/3))` → `3`.

리다이렉션은 명령어의 **입력/출력 방향**을 바꾸는 기능이다. 파일 디스크립터 번호는 `0=표준입력(stdin)`, `1=표준출력(stdout)`, `2=표준오류(stderr)` 로 고정되어 있다. `>` 는 표준 출력을 파일로 **덮어쓰기(overwrite)**(파일이 없으면 생성), `>>` 는 표준 출력을 파일에 **추가(append)**(기존 내용 보존), `2>` 는 표준 오류만 파일로 저장(정상 출력은 화면 그대로), `2>&1` 은 표준 오류를 표준 출력과 같은 곳으로 합친다. `명령 > /dev/null 2>&1` 은 정상/오류 출력 모두 숨기는 표준 관용구다. `<` 는 파일 내용을 명령의 표준 입력으로 전달하며, `<<` (Here-document)는 스크립트 안에서 여러 줄 입력을 직접 지정할 때 사용하며 지정한 종료문자(EOF 등)를 만날 때까지 내용을 그대로 전달한다.

세미콜론(`;`), `&&`, `||` 는 모두 명령을 연결하지만 **직전 명령의 성공/실패 여부를 보는지 여부**가 다르다. `;` 는 앞 명령의 성공 여부와 무관하게 무조건 다음 명령을 실행하는 단순 순차 실행이고, `&&` 는 앞 명령이 성공(exit 0)해야 다음 명령을 실행하는 조건 기반 AND, `||` 는 앞 명령이 실패(exit 1 이상)해야 다음 명령을 실행하는 조건 기반 OR(실패 시 보완)이다. `mkdir test && cd test` 는 디렉터리 생성이 성공해야만 이동한다. 이미 존재해서 `mkdir` 이 실패하면 `cd` 는 실행되지 않는다. `cd abc || echo "실패"` 는 `cd` 실패 시에만 메시지를 출력한다. `{ 명령1; 명령2; } && 명령3 || echo 실패` 처럼 중괄호로 명령을 그룹화하여 복합 조건을 구성할 수 있다.

`~` 는 **경로의 맨 앞에서만** 현재 사용자의 홈 디렉터리로 자동 치환된다. `~계정명` 형태로 특정 사용자의 홈 디렉터리도 지정할 수 있다(예: `~root` → `/root`, `~guest` → `/home/guest`). 쉘은 명령을 실행하기 **전에** `~` 를 실제 경로로 미리 치환한다. `ls ~/Downloads` 는 실제로 `ls /home/sol/Downloads` 와 동일하게 동작한다.

## 2. 🛠️ 표준 설정 템플릿 (Configuration)

### 2-1. 메타문자 6대 분류 요약표

| 분류 | 대표 문자 |
|---|---|
| ① 글롭(glob) / 패턴 매칭 | `*`, `?`, `[]`, `[! ]`, `[a-z]` |
| ② 중괄호 확장(Brace Expansion) | `{a,b}`, `{1..5}`, `{a..z}` |
| ③ 변수·치환·산술 | `$`, `${}`, `$()`, `` ` ` ``, `$(())`, `~` |
| ④ 리다이렉션/파이프 | `>`, `>>`, `<`, `<<`, `<<<`, `\|`, `2>`, `&>`, `2>&1` |
| ⑤ 명령 연결/제어 | `;`, `&&`, `\|\|`, `&`, `()`, `{}`, `\` |
| ⑥ 주석 | `#` |

### 2-2. 글롭 패턴 실전 예시

```bash
ls file[abc].txt          # filea.txt, fileb.txt, filec.txt
ls file[0-9].txt          # file0.txt ~ file9.txt
ls file[0-9][0-9]         # 두 자리 숫자 (file00 ~ file99)
ls backup?                # backupA, backupB ... (정확히 1글자)
ls *.[pj][np]g            # .png 또는 .jpg
ls [A-Z]*                 # 대문자로 시작하는 파일
ls file[^ABC]*             # fileA/B/C를 제외한 file*
ls .[0-9]*                 # 숨김파일 중 두 번째 문자가 숫자
```

### 2-3. 중괄호 확장 실전 예시

```bash
echo file{1,3,7}.txt              # file1.txt file3.txt file7.txt
echo file{1..5}.txt                # file1.txt ~ file5.txt
echo img{001..010}.png             # 0 패딩 범위 확장
mkdir -p /data/{log,backup,temp}   # 디렉터리 3개 한 번에 생성
mkdir -p project/{src,bin,conf}/{dev,prod}   # 중첩 조합 (2x3=6개 경로)
echo web-{dev,prod}-{1,2}          # web-dev-1 web-dev-2 web-prod-1 web-prod-2
```

### 2-4. 환경변수 참조 + 변수 치환 실전 패턴

```bash
# 표준 환경변수 참조 — 메타문자 확장 컨텍스트
echo "사용자: $USER"        # 로그인 사용자 이름
echo "홈: $HOME"            # 홈 디렉터리
echo "쉘: $SHELL"           # 기본 쉘 경로
echo "경로: $PATH"          # 명령어 탐색 경로

# 일반 예제 변수 (강의에서 자주 사용하는 패턴)
var="값"                    # 단순 문자열 변수
message="Hello, World"     # 메시지 변수
filename="test.txt"        # 파일명 변수
cnt=10                      # 카운터 변수
count=0                     # 반복용 카운터
files="file1 file2 file3"  # 파일 목록 변수
city="Seoul"                # 도시 변수

echo $var
echo $message
echo $filename
echo $cnt
echo $count
echo "$files"
echo $city

# 명령 치환 — 추가 실전 패턴
echo $(ls -l | wc -l)      # 현재 디렉터리 상세 줄 수
echo $(whoami)              # 현재 사용자 이름 출력
```

### 2-5. 파일 테스트 플래그 + Bash 내장 명령

```bash
# 파일 테스트 — [[ ]] 또는 [ ] 안에서 사용하는 플래그 (메타문자 확장 컨텍스트)
[[ -f "$file" ]]   # 일반 파일(-f)인지 확인
[[ -d "$dir" ]]    # 디렉터리(-d)인지 확인
[[ -r "$file" ]]   # 읽기 권한(-r) 있는지 확인
[[ -x "$file" ]]   # 실행 권한(-x) 있는지 확인
[[ -n "$var" ]]    # 변수가 비어있지 않으면(-n) 참
[[ -h "$link" ]]   # 심볼릭 링크(-h)인지 확인
[[ -b "$dev" ]]    # 블록 디바이스(-b)인지 확인
[[ -c "$dev" ]]    # 문자 디바이스(-c)인지 확인
[[ -k "$dir" ]]    # sticky bit(-k) 설정 여부
[[ -a "$file" ]]   # 파일 존재(-a, -e 와 동일)

# Bash 내장 명령 (메타문자 처리에 관련된 명령)
set                # 현재 쉘 변수·함수 목록 조회
set -x             # 디버그 모드: 실행 명령 추적 출력
source ~/.bashrc   # 파일을 현재 쉘에서 실행 (. 과 동일)

myfunc() {
    local var="지역변수"   # local : 함수 내부 전용 변수
    echo "$var"
}
```

### 2-6. 변수·치환 표준 사용법

```bash
# 변수 확장 (큰따옴표 권장)
echo "$변수명"

# 변수명 뒤 문자열 구분
echo "${변수명}추가문자"

# 명령 치환 (현재 방식, 백틱은 비권장)
결과=$(명령어)

# 중첩 명령 치환
echo "현재 디렉터리: $(basename $(pwd))"

# 산술 확장 (값 반환)
echo $((변수1 + 변수2))
echo $((10 + 5 * 5))        # 우선순위 적용 → 35

# 비교 연산자 — 결과: 1(참) / 0(거짓)
echo $((10 > 5))             # 1
echo $((10 == 10))           # 1
echo $((10 != 5))            # 1

# 논리 연산자 (&&, ||, !)
echo $((10 > 5 && 20 < 30))  # 1  (AND)
echo $((10 > 5 || 20 > 30))  # 1  (OR)
echo $(( !(10 < 20) ))       # 0  (NOT: 10<20 은 참이므로 NOT 하면 거짓)

# 중첩 — 명령치환 결과를 산술 확장에 넣기
count=$(( $(ls -l | wc -l) - 1 ))   # 헤더 줄 제외한 파일 수

# 산술 평가 (조건 판단, 종료 코드 반환)
(( 변수 > 5 )) && echo "참"

# 명령 치환 — 다양한 실전 패턴
today=$(date)                   # 현재 날짜·시간 전체
today=$(date +%F)               # YYYY-MM-DD 형식
now_t=$(date +%T)               # HH:MM:SS 시각
now_r=$(date +%R)               # HH:MM 시각(초 제외)
date_d=$(date +%D)              # MM/DD/YY 미국 형식
myip=$(hostname -I)             # 서버 IP 주소 조회
mysh=$(which bash)              # bash 실행파일 경로
user_cnt=$(who | wc -l)         # 로그인 사용자 수
file_cnt=$(ls | wc -l)          # 현재 디렉터리 파일 수
log_cnt=$(ls /var/log)          # /var/log 파일 목록
detail_cnt=$(ls -l /temp | wc -l)   # /temp 파일 상세 줄 수
echo "오늘: $today / IP: $myip / 사용자: $user_cnt"
```

### 2-7. 산술 확장 종합 예제 (숫자·변수·증감·대입·비교)

```bash
# 기본 사칙연산
echo $((10 + 3))             # 13
echo $((10 - 3))             # 7
echo $((10 * 3))             # 30
echo $((10 / 3))             # 3  (정수 나눗셈, 소수점 버림)
echo $((10 % 3))             # 1  (나머지)
echo $((10 ** 3))            # 1000 (제곱)
echo $((15 / 4))             # 3
echo $((10 + 20))            # 30
echo $((10 + 15))            # 25

# 비교 연산 (결과: 1=참, 0=거짓)
echo $((10 < 20))            # 1
echo $((10 > 5))             # 1

# 논리 조합 (AND / OR 변형 포함)
echo $((10 > 5 && 20 > 30))  # 0  (AND: 두 번째 조건이 거짓)
echo $((10 > 5 || 20 < 30))  # 1  (OR: 둘 중 하나라도 참)

# 증감 연산자
num=5
echo $((++num))              # 6  (전위 증가: 먼저 증가 후 반환)
echo $((num++))              # 6  (후위 증가: 먼저 반환 후 증가)
echo $((--num))              # 6  (전위 감소)
echo $((num--))              # 6  (후위 감소)

# 복합식 (괄호 그룹화)
echo $(( (10 + 5) ))         # 15  (괄호로 그룹화)
echo $(( (10 < 20) ))        # 1   (조건을 괄호로 그룹)
echo $(( (50 - 20) ))        # 30
echo $((10 + 5 * 5))         # 35  (연산자 우선순위 적용)

# 변수 대입 복합 연산
x=10; y=20
echo $((x + y))              # 30
echo $((x * y))              # 200
result=$((x + y))
echo $result

# 나머지로 홀짝 판단 패턴
for num in 1 2 3 4 5
do
    if (( num % 2 == 0 ))
    then echo "$num : 짝수"
    else echo "$num : 홀수"
    fi
done

# 복합 대입 연산자 (산술식) — 공백 있는 형식 / 없는 형식 모두 유효
num=10
echo $((num += 1))     # 11  (덧셈 대입)
echo $((num += 5))     # 공백 있는 형식
echo $((num+=5))       # 16  (공백 없는 형식도 동일하게 동작)
echo $((num *= 2))     # 곱셈 대입 (공백 있는 형식)
echo $((num*=2))       # 공백 없는 형식

# 변수 조합 산술
a=7; b=3
echo $((a + b))        # 10
echo $((a * b))        # 21
echo $((a < b))        # 0  (7 < 3 은 거짓)
echo $((7 + 3))        # 10
echo $((27 % 5))       # 2
echo $((3 + 2 * 8))    # 19  (우선순위)

# 변수 참조 산술
cnt=5
echo $((cnt))          # 5  (단일 변수 산술 확장)
echo $((num + 10))     # 변수 + 리터럴

# 수학 함수 패턴 (제곱 조합)
x=3; y=4
echo $((x**2 + y**2))  # 25  (피타고라스 공식)

# 일반 형식 (산술식 자리에 다양한 식 사용 가능)
echo $(( 산술식 ))         # 산술식 예시 자리 표시
result=$(command)          # 명령 치환 일반 형식
echo "결과: $result"
```

### 2-8. 리다이렉션 표준 패턴

```bash
명령 > 파일                  # 표준 출력 덮어쓰기
명령 >> 파일                 # 표준 출력 추가
명령 2> 파일                 # 표준 오류만 저장
명령 2>> 파일                # 표준 오류 추가
명령 > 파일 2>&1             # 정상+오류 모두 같은 파일로
명령 > /dev/null 2>&1        # 정상+오류 모두 화면에서 숨김
명령 < 파일                  # 파일을 표준 입력으로
명령 << EOF                  # Here-document
내용
EOF
```

### 2-9. 명령 연결/제어 표준 패턴

```bash
명령1; 명령2                       # 무조건 순차 실행
명령1 && 명령2                     # 명령1 성공 시에만 명령2 실행
명령1 || 명령2                     # 명령1 실패 시에만 명령2 실행
{ [ -d /경로 ] || mkdir /경로; } && chmod 770 /경로 || echo "실패"
```

## 3. 🔍 검증 및 트러블슈팅 (Verification & Troubleshooting)

### 3-1. 필수 검증 명령어

```bash
printf '%s\n' <패턴>            # 글롭/중괄호 확장 결과를 실행 전 미리 확인 (실수 방지 필수)
echo $?                         # 직전 명령 종료 코드 확인
env | grep <변수명>              # 환경 변수 등록 여부 확인
type <명령어>                    # 명령어 경로/별칭 확인
```

### 3-2. 트러블슈팅 시나리오

#### 🚨 시나리오 1. 중괄호 확장이 되지 않고 문자 그대로 출력됨

- **원인 후보:** ① 콤마 뒤에 공백이 있음(`File{A, B, C}`), ② 중괄호 표현 전체를 따옴표로 감쌈(`"file{1,2,3}.txt"`).
- **해결:** 공백 제거, 중괄호 확장 부분만 따옴표 밖에 두거나 앞뒤만 따옴표로 감싼다.
  ```bash
  echo "file"{1,2,3}".txt"     # 정상 확장됨
  ```

#### 🚨 시나리오 2. 파괴적 명령(`rm -rf`, `chmod -R` 등)에 글롭/중괄호 패턴을 바로 실행해 의도치 않은 범위가 삭제됨

- **원인:** 패턴이 예상보다 넓게 매치됨.
- **해결/예방:** 실행 전 반드시 `ls` 또는 `printf '%s\n'` 으로 매칭 대상을 먼저 확인한 뒤 실행한다.
  ```bash
  printf '%s\n' /backup/a*      # 실제 삭제 대상 미리 확인
  rm -rf /backup/a*             # 확인 후 실행
  ```

#### 🚨 시나리오 3. `usermod -G` 처럼 변수 확장이 필요한 명령에서 작은따옴표를 사용해 변수가 확장되지 않음

- **증상:** `echo 'Hello $name'` → `Hello $name` 그대로 출력.
- **원인:** 작은따옴표는 모든 메타문자를 일반 문자로 처리.
- **해결:** 변수 확장이 필요하면 큰따옴표 사용.
  ```bash
  echo "Hello $name"
  ```

#### 🚨 시나리오 4. `2>` 를 반복 실행했더니 로그가 계속 덮어써짐

- **증상:** 동일한 오류를 여러 번 `2>` 로 저장했더니 파일에 마지막 1건만 남음.
- **원인:** `>` (그리고 `2>`)는 매번 파일을 덮어쓰기 때문.
- **해결:** 누적 기록이 필요하면 `2>>` (append) 사용.
  ```bash
  ls -l 없는파일 2>> error.log
  ```

#### 🚨 시나리오 5. `&&` 로 연결된 명령 중간이 실패했는데 뒤 명령까지 실행될 것으로 착각

- **원인:** `&&` 는 왼쪽이 실패하면 즉시 체인이 중단된다는 점을 놓침(`;` 과 혼동).
- **해결:** 순서 보장이 필요 없는 무조건 실행은 `;`, 성공 시에만 이어가야 하는 작업은 `&&` 로 구분해서 설계한다.

#### 🚨 시나리오 6. `PATH2="my value"` 처럼 공백이 있는 값을 export 했는데 여러 인자로 쪼개짐

- **원인:** 참조 시 큰따옴표 없이 `$변수` 를 사용하면 공백 기준으로 단어가 분리(word splitting)된다.
- **해결:** 항상 `"$변수"` 형태로 참조한다.
  ```bash
  echo "$PATH2"     # my value (하나의 문자열로 유지)
  ```
