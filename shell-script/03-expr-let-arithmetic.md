# 🔢 Shell Script - expr · let (산술 연산)

> **Tag:** #Linux #ShellScript #Bash #expr #let #산술연산
> **핵심 요약:** `expr` 는 정수·문자열 연산과 비교를 수행하고 결과를 **표준출력으로만** 내보내는 가장 오래된 외부 명령어 기반 산술 도구이며, `let` 는 Bash 내장 명령으로 **변수에 직접 값을 대입**하는 정수 전용 산술 계산기이다. 두 도구 모두 결과를 화면에 자동 출력하지 않으므로 `echo` 또는 `$( )` 치환이 필요하다.

---

## 1. 📖 개요 (Overview)

`expr` 는 값과 연산자를 **모두 별도의 인자(문자열 토큰)**로 인식하기 때문에 `expr 3+7` 처럼 공백 없이 붙이면 하나의 문자열로 처리되어 오류가 난다. 기본 형식은 `expr 값1 연산자 값2` 이며 모든 토큰 사이에 공백이 필수다. 또한 `*` 는 쉘이 먼저 해석하는 글롭 메타문자이므로, escape(`\*`)하지 않으면 현재 디렉터리 파일 목록으로 잘못 확장될 수 있다. `>`, `<` 같은 비교 연산자도 쉘의 리다이렉션 메타문자와 충돌하므로 마찬가지로 escape가 필요하다. `expr` 는 연산 결과를 **표준출력으로만** 보여줄 뿐 변수에 자동으로 저장하지 않으므로, 변수에 담으려면 `$( )` 로 감싸야 한다. 예를 들어 `sum=$(expr 10 + 20)` 처럼 작성한다.

`let` 는 `expr` 와 달리 Bash **내장(built-in) 명령**으로, 변수 앞에 `$` 없이 바로 대입식을 쓸 수 있고(`let x=5+3`), 계산과 동시에 **변수에 결과를 직접 저장**한다. 반면 `expr` 는 외부 명령으로 결과를 화면에 출력만 할 뿐 변수 저장은 별도의 치환이 필요하다. `let` 도 정수(Integer) 계산만 가능하며 소수점은 버려진다(`5/2` → `2`). 공백이 포함된 대입식은 반드시 따옴표로 감싸야 하는데, `let "x = 5 + 3"` 은 정상이지만 `let x = 5 + 3` 은 오류가 난다. `let` 역시 계산만 하고 화면에 자동 출력하지 않으므로 확인하려면 `echo $변수` 를 사용해야 하며, `let x++`, `let x--` 처럼 증감 연산자도 그대로 지원한다.

실무에서는 `expr`/`let` 대신 `$(( ))` 를 더 선호하는데, 이는 Bash **내장 산술 확장**으로 외부 프로세스를 호출하지 않아 성능이 좋고, `*`, `>` 같은 메타문자를 escape 할 필요가 없으며, 비교·논리 연산까지 한 구문 안에서 자연스럽게 처리할 수 있어 대부분의 최신 스크립트에서 우선적으로 사용되기 때문이다. 다만 `expr` 는 POSIX 호환성이 필요한 아주 오래된 쉘 스크립트에서, `let` 는 변수 증감이 잦은 반복문에서 여전히 종종 사용된다. 세 방식(`expr`, `let`, `$(( ))`) 모두 **정수 연산만** 지원하며, 소수점 계산은 `bc` 또는 `awk` 등 별도 도구가 필요하다는 공통 한계가 있다.

## 2. 🛠️ 표준 설정 템플릿 (Configuration)

> **적용 환경:** Bash 기반 Linux 셸 환경 (RHEL 계열 기본 `/bin/bash`).

### Step 1. expr 기본 문법

```bash
expr 값1 연산자 값2

# 사칙연산
expr 3 + 4              # 덧셈
expr 10 \* 2             # 곱셈 ( * 는 반드시 \* 로 escape )
expr 7 / 2               # 나눗셈 (정수 나눗셈)
expr 29 % 5              # 나머지

# 결과를 변수에 저장 (반드시 $( ) 치환 필요)
sum=$(expr 10 + 20)
echo "결과: $sum"

# 두 변수의 연산
a=7
b=5
expr $a + $b
expr $a \* $b
total=$(expr $a + $b)
```

### Step 2. expr 비교 연산 (참=0, 거짓=1 반환)

```bash
expr $x = $y             # 같으면 0(참), 아니면 1
expr $x \> $y             # 크면 0(참) — > 도 escape 필요
expr $x \>= $y            # 크거나 같으면 0(참)
```

### Step 3. expr 1 증가 패턴

```bash
i=7
i=$(expr $i + 1)
echo $i        # 8
```

### Step 4. let 기본 문법

```bash
let x=3+5                # 대입 (앞에 $ 불필요)
let x++                  # 1 증가
let x--                  # 1 감소
let y=x*2                # 곱셈

# 공백 포함 시 반드시 따옴표
let "x = 5 + 3"          # 정상
# let x = 5 + 3          # 오류

# 결과 확인은 echo로
echo $x
```

### Step 5. let 실전 패턴

```bash
let x=10
let x+=5          # 15로 갱신

let n=1
let n++           # 2로 증가

let count=10
let count--       # 9로 감소

let a=6; b=3
let c=a*b         # c=18

let x=15
let x/=2          # 몫으로 갱신 (7)

let y=17
let r=y%4         # 나머지 (1)

# expr로 합계 구하기
a=3; b=5; c=7
total=$(expr $a + $b + $c)
echo "합계 : $total"       # 15
```

## 3. 🔍 검증 및 트러블슈팅 (Verification & Troubleshooting)

### 3-1. 필수 검증 명령어

```bash
echo $?              # expr/let 실행 후 결과값이 아닌 "성공 여부"를 확인하고 싶을 때
echo $변수            # 계산 결과가 실제로 저장되었는지 확인
type expr             # expr가 외부 명령임을 확인 (/usr/bin/expr)
type let              # let가 쉘 내장 명령임을 확인
```

### 3-2. 트러블슈팅 시나리오

#### 🚨 시나리오 1. `expr 3+7` 실행 시 오류 또는 의도치 않은 결과

- **원인:** 공백 없이 값과 연산자를 붙여 써서 하나의 문자열 토큰(`"3+7"`)으로 인식됨.
- **해결:**
  ```bash
  expr 3 + 7      # 값, 연산자 사이에 반드시 공백
  ```

#### 🚨 시나리오 2. `expr 10 * 2` 실행 시 파일 목록이 출력되거나 오류 발생

- **원인:** `*` 가 쉘 글롭 메타문자로 먼저 해석되어 현재 디렉터리의 모든 파일명으로 확장됨.
- **해결:**
  ```bash
  expr 10 \* 2     # 백슬래시로 escape
  ```

#### 🚨 시나리오 3. `expr` 결과가 변수에 저장되지 않음

- **증상:** `expr 10 + 20` 을 실행해도 이후 `echo $sum` 이 비어 있음.
- **원인:** `expr` 는 결과를 표준출력으로만 내보낼 뿐 변수에 자동 저장하지 않음.
- **해결:**
  ```bash
  sum=$(expr 10 + 20)
  echo "$sum"
  ```

#### 🚨 시나리오 4. `let x = 5 + 3` 실행 시 오류 발생

- **원인:** 공백이 포함된 대입식을 따옴표 없이 실행함.
- **해결:**
  ```bash
  let "x = 5 + 3"
  ```

#### 🚨 시나리오 5. `let` 로 나눗셈했더니 소수점 결과가 기대와 다름

- **증상:** `let x=5/2` 실행 후 `echo $x` → `2` (2.5가 아님).
- **원인:** `let` 는 정수 연산만 지원하여 소수점 이하가 버려짐.
- **해결:** 소수점 계산이 필요하면 `bc` 사용.
  ```bash
  echo "5/2" | bc -l    # 2.50000000000000000000
  ```

---

> 📌 **핵심 요약**
> - `expr` : 값·연산자 사이 공백 필수, `*`/`>` 등은 escape 필요, 결과는 `$( )` 로 변수에 저장
> - `let` : 변수 앞 `$` 불필요, 공백 있는 식은 따옴표로 감쌈, 결과 확인은 `echo`
> - 두 도구 모두 **정수 전용**이며, 실무에서는 `$(( ))` 산술 확장이 더 널리 사용됨
