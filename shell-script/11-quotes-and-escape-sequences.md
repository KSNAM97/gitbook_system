# Shell Script - Quotes(따옴표)와 Escape Sequences 심화

> **Tag:** #Linux #ShellScript #Bash #Quotes #SingleQuotes #DoubleQuotes #EscapeSequences #printf
> **핵심 요약:** 따옴표는 숫자·문자열을 구분하는 용도가 아니라 **단어 분리·globbing·메타문자 해석을 막는(escape) 용도**로 쓰인다. 작은따옴표(`'`)는 모든 문자를 무조건 원문 그대로 취급하고, 큰따옴표(`"`)는 `$`, `` ` ``, `\`, 개행만 특별하게 처리하며 나머지는 그대로 유지한다. `$' '`은 이스케이프 시퀀스를 해석하는 작은따옴표다.

---

## 1. 개요 (Overview)

Shell에서 따옴표의 용도는 다섯 가지로 정리된다: ① 공백으로 분리되는 여러 문자열을 하나의 인수로 묶을 때, ② 줄바꿈이나 여러 개의 공백을 그대로 유지할 때, ③ 단어 분리(word splitting)·globbing을 방지할 때, ④ `$`, `` ` ``, `!` 같은 쉘 메타문자를 단순 문자로 만들 때, ⑤ 문자열을 시각적으로 강조할 때. 쉘 메타문자 중 `$`는 매개변수 확장·산술 확장·명령 치환, `` ` ``는 명령 치환(구식), `!`는 history 확장에 사용된다.

**따옴표 없이(No quotes)** 문자열을 쓰면 공백은 인수 구분자로 쓰이고(둘 이상의 공백은 하나로 취급), `\`로 공백이나 메타문자를 개별 escape할 수 있다. 줄 끝에 `\`를 붙이고 개행하면 `\`+개행이 하나로 이어져 처리된다(backslash-newline). `echo -e foo \` 뒤에 다음 줄에서 이어 쓰는 것이 그 예다.

**큰따옴표(`""`)** 로 감싼 문자열은 내부의 `"`, `$`, `` ` ``, `\`, 개행만 escape할 수 있고 나머지 특수문자는 무력화된다 — 즉 변수 확장(`$var`)·명령 치환(`` `cmd` ``, `$(cmd)`)·산술 확장(`$((..))`)은 큰따옴표 안에서도 그대로 동작하며, 공백과 개행은 유지된다. `AA="line1\nline2"` 처럼 여러 줄 문자열을 만들었을 때 `echo "$AA"`로 출력해야 개행이 유지되고, `echo $AA`(quote 없음)로 출력하면 단어 분리가 일어나 한 줄로 뭉개진다. 배열을 다룰 때는 `"${arr[@]}"`(각 원소를 개별 인용 — `"${arr[0]}" "${arr[1]}" ...`과 동일)와 `"${arr[*]}"`(전체를 하나의 문자열로 결합 — `"${arr[0]}X${arr[1]}X..."`, X는 `$IFS`의 첫 글자)의 의미가 다르므로 배열 비교·순회 목적에 맞게 골라 써야 한다. 변수가 NULL인 경우 quote하지 않으면 인수 자체가 사라진다(`echo yy $AA zz` → `AA`가 빈 값이면 `yy zz`), quote하면 빈 문자열 인수로 유지된다(`echo yy "$AA" zz` → `yy  zz`). 오류 메시지도 quote했을 때 더 명확하게 나오므로, 특별한 이유가 없다면 변수는 항상 큰따옴표로 참조하는 것이 안전하다.

**작은따옴표(`''`)** 로 감싼 문자열은 내부 모든 문자를 완전히 원문 그대로 취급하며 어떤 확장도 escape도 일어나지 않는다. 작은따옴표로 감싼 문자열 내부에 작은따옴표 자체를 넣으려면 ① `no quotes` 상태에서 `\'`로 escape하거나(`echo 'test'\''test'`), ② 작은따옴표를 잠깐 닫고 큰따옴표로 `'`를 감싼 뒤 다시 작은따옴표를 여는 방법(`echo 'test'"'"'test'`)을 쓴다. 작은따옴표가 특히 필요한 경우는 세 가지다: ① 명령어 문자열(Command String)을 만들 때(큰따옴표를 쓰면 스크립트 작성 시점의 변수값이 미리 확장되어 실행 시점에 원하는 동작을 하지 않을 수 있음), ② trap 핸들러 지정 시, ③ 프롬프트(PS1 등) 설정 시. `$' '`은 escape 시퀀스를 해석할 수 있는 작은따옴표로, 처리 후에는 `$`가 제거된 일반 작은따옴표 문자열이 된다(`foo=$'aaa\nbbb'; echo "$foo"` 는 `-e` 옵션 없이도 개행이 해석됨). `sh`에서는 `$' '` 를 사용할 수 없다.

두 개의 quotes를 공백 없이 붙여 쓰면 하나의 인수로 합쳐진다. 이는 변수를 포함한 명령 문자열을 만들거나 명령에 전달할 인수를 하나로 합칠 때 유용하다. 예를 들어 `sed -E 's/'"$var1/$var2"'/g'` 는 작은따옴표로 감싼 sed 표현식 중간에 변수가 들어갈 부분만 큰따옴표로 바꿔 붙여 쓴 형태다. `printf %q`는 인수나 명령 문자열 전체를 다른 명령에 안전하게 전달할 수 있도록 이스케이프해 주는 지정자로, 이스케이프 문자가 포함된 문자열은 `$' '` 형태로 출력해 준다.

**Escape Sequences(이스케이프 시퀀스)** 는 `echo -e`, `$' '`, `printf`(`""`, `''`, `%b`)에서 처리되며, `sh`의 `echo`는 옵션 없이도(`-e` 없이도) 항상 이스케이프 문자를 처리한다는 점이 bash와 다르다. 8진수·16진수 표기도 컨텍스트별로 지원 범위가 다르다: `\NNN`(8진수)은 `printf`와 `$' '`에서, `\0NNN`(8진수)은 `echo`에서, `\xHH`(16진수)는 대부분의 컨텍스트에서 처리된다. `sh`에서는 `echo`·`printf` 모두 16진수를 지원하지 않으므로, `sh`와 `bash` 양쪽에서 동작하게 하려면 8진수 표기를 사용해야 한다. 작은따옴표(`' '`)는 `\NNN`·`\0NNN` 8진수를 처리하지 못하지만, `printf '%b'`는 모든 이스케이프 문자를 처리한다.

## 2. 표준 설정 템플릿 (Configuration)

> **적용 환경:** Bash 기반 Linux 셸 환경 (RHEL 계열 기본 `/bin/bash`).

### Step 1. 큰따옴표 vs 작은따옴표 비교

```bash
name="Park"
echo "Hello $name"      # Hello Park   (변수 확장 O)
echo 'Hello $name'      # Hello $name  (변수 확장 X)

AA="line1
line2"
echo $AA                # line1 line2  (quote 없음 → 단어 분리로 한 줄)
echo "$AA"               # line1        (quote → 개행 유지)
                          # line2
```

### Step 2. 작은따옴표 안에 작은따옴표 넣기

```bash
echo 'test'\''test'        # test'test  (no quotes 상태에서 escape)
echo 'test'"'"'test'       # test'test  (큰따옴표로 ' 만 감싸기)
```

### Step 3. `$' '` 로 이스케이프 문자 처리

```bash
foo=$'aaa\nbbb'
echo "$foo"                 # -e 없이도 개행이 해석됨
# aaa
# bbb
```

### Step 4. Quotes 붙여 쓰기 (인수/명령 문자열 합치기)

```bash
var1="foo"; var2="bar"
sed -E 's/'"$var1"'/'"$var2"'/g' file.txt   # 작은따옴표 안에 변수 부분만 큰따옴표로 교체
```

### Step 5. Escape Sequences 표준 패턴

```bash
echo -e "tab:\t newline:\n"       # bash echo, -e 필요
printf '%b\n' "tab:\t newline:\n"  # printf %b, 8진/16진 이스케이프까지 모두 처리
printf '%q\n' "foo bar*"          # 다른 명령에 안전하게 전달할 형태로 escape
```

### Step 6. 배열과 관련된 quotes 차이

```bash
arr=("a b" "c" "d")
for x in "${arr[@]}"; do echo "[$x]"; done   # 각 원소를 개별 인용: [a b] [c] [d]
echo "${arr[*]}"                              # 전체를 IFS 첫 글자로 이어붙인 하나의 문자열
```

### Step 7. 8진수/16진수 이스케이프 문자 지원 범위

| 이스케이프 | 뜻 | 지원 범위 |
|---|---|---|
| `\NNN` | 8진수 | `printf`, `$' '` |
| `\0NNN` | 8진수 | `echo` |
| `\xHH` | 16진수 | 대부분(`sh`의 `echo`/`printf`는 미지원) |

```bash
printf '\101\102\103\n'        # ABC (8진수, printf)
echo -e '\0101\0102\0103'      # ABC (8진수, echo 전용 \0 접두)
printf '\x41\x42\x43\n'        # ABC (16진수, bash printf만 지원)
```

### Step 8. sh vs bash에서 echo/printf 이스케이프 차이

```bash
# bash: -e 옵션 필요
echo "a\tb"        # a\tb  (그대로 출력)
echo -e "a\tb"      # a	b  (탭으로 해석)

# sh: 옵션 없이 항상 이스케이프 처리 (환경에 따라 dash 등으로 연결됨)
sh -c 'echo "a\tb"'   # a	b
```

## 3. 검증 및 트러블슈팅 (Verification & Troubleshooting)

### 3-1. 필수 검증 명령어

```bash
echo "$변수"          # 항상 큰따옴표로 참조하는 습관 확인
declare -p 변수명       # 변수에 실제로 저장된 값(공백·개행 포함) 확인
```

### 3-2. 트러블슈팅 시나리오

#### 시나리오 1. 변수에 공백이 있는 값을 담았는데 여러 인자로 쪼개짐

- **원인:** `$변수`를 quote 없이 참조하면 IFS(공백)에 의해 단어 분리(word splitting)가 일어난다.
- **해결:** 항상 `"$변수"` 형태로 참조한다.
  ```bash
  path2="my value"
  echo "$path2"     # my value (하나의 문자열로 유지)
  ```

#### 시나리오 2. 변수 값에 `*` 같은 glob 문자가 들어있는데 원치 않는 파일 목록으로 확장됨

- **원인:** `echo $AA` 처럼 quote 없이 참조하면 값에 포함된 glob 문자가 실제 파일명 매칭(globbing)으로 확장될 수 있다.
- **해결:** `echo "$AA"` 로 quote해서 참조하면 globbing이 발생하지 않는다.

#### 시나리오 3. 큰따옴표 안에 작은따옴표를 잘못 섞어 스크립트가 깨짐

- **원인:** 작은따옴표는 내부에서 어떤 문자도 escape할 수 없으므로, 작은따옴표로 감싼 문자열 안에 작은따옴표 자체를 그대로 넣을 수 없다.
- **해결:** `'...'\''...'` 또는 `'...'"'"'...'` 패턴으로 작은따옴표 문자 자체를 분리해서 이어 붙인다.

#### 시나리오 4. `echo`로 이스케이프 문자를 출력했는데 `\t`, `\n`이 문자 그대로 출력됨

- **원인:** bash의 `echo`는 기본적으로 이스케이프 문자를 해석하지 않으며 `-e` 옵션이 필요하다(`sh`의 `echo`와 다른 점).
- **해결:** `echo -e` 또는 `printf '%b'`를 사용한다.

#### 시나리오 5. 스크립트를 `sh`로도 실행했더니 `\x41` 같은 16진수 이스케이프가 그대로 출력됨

- **원인:** `sh`의 `echo`·`printf`는 16진수(`\xHH`) 이스케이프를 지원하지 않는다.
- **해결:** `sh`와 `bash` 양쪽에서 동일하게 동작해야 한다면 16진수 대신 8진수(`\NNN`)로 통일해서 작성한다.

#### 시나리오 6. `$var1/$var2`를 포함한 `sed` 표현식을 작은따옴표로 감쌌더니 변수가 확장되지 않음

- **원인:** 작은따옴표 안의 `$var1`, `$var2`는 원문 그대로 취급되어 변수 확장이 일어나지 않는다.
- **해결:** 변수가 들어갈 부분만 큰따옴표로 분리해서 붙여 쓴다(`'s/'"$var1"'/'"$var2"'/g'`).

>  **핵심 요약**
> - 따옴표는 타입 구분용이 아니라 단어 분리·globbing·메타문자 해석을 막는 용도
> - 큰따옴표: `$`, `` ` ``, `\`, 개행만 특별 처리(변수·명령·산술 확장은 유지) / 작은따옴표: 모든 문자 원문 그대로
> - `$' '`는 이스케이프 시퀀스를 해석하는 작은따옴표(sh에서는 사용 불가)
> - `"${arr[@]}"`(개별 인용)와 `"${arr[*]}"`(하나로 결합)는 의미가 다름 — 배열 비교엔 `*`, 순회엔 `@`
